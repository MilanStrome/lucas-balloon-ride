# Assets and their sources

Everything the game shows or plays is either generated in code or under an open licence.
No image, sound or font is downloaded at runtime.

| Asset                                                                                                                                     | Where                                                                                          | Source / licence                                                                                                                                             |
| ----------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| SN Pro, weight 900 (Black), Latin + Latin Extended WOFF2                                                                                  | `public/fonts/sn-pro-latin-900-normal.woff2`, `public/fonts/sn-pro-latin-ext-900-normal.woff2` | SN Pro by the SN Pro Project Authors (Supernotes), via `@fontsource/sn-pro` 5.3.0. SIL Open Font License 1.1, copied to `public/fonts/OFL.txt`. Self-hosted. |
| Balloon, rider placeholders, stars, coins, birds, bees, clouds, trees, asteroids, power-ups, fireflies, landing pad, parallax backgrounds | `src/render/art/*.ts`                                                                          | Procedural Canvas 2D drawing written for this project.                                                                                                       |
| UI icons                                                                                                                                  | `src/ui/icons.ts`                                                                              | Inline SVG drawn for this project.                                                                                                                           |
| Avatars                                                                                                                                   | `src/ui/avatars.ts`                                                                            | Procedural SVG written for this project.                                                                                                                     |
| Placeholder rider art slot ("Sample Rider")                                                                                               | `public/characters/sample-rider/*.svg`                                                         | Hand-written SVG for this project, labelled PLACEHOLDER. To be replaced by RV AppStudios' Lucas & Friends art.                                               |
| App icons (192, 512, maskable 512, Apple touch 180)                                                                                       | `public/icons/*.png`                                                                           | Rasterized by `scripts/gen-icons.ts` (own code, no dependencies).                                                                                            |
| Sound effects (chime, coin, pop, whoosh, bounce, hit, cheer, click, blow-out)                                                             | `src/audio/Sfx.ts`                                                                             | Synthesized live with Web Audio oscillators/filtered noise. No files.                                                                                        |
| Music (menu, one loop per world, calm, party)                                                                                             | `src/audio/Music.ts`                                                                           | Synthesized live by a small step sequencer written for this project. No files.                                                                               |
| Test audio fixtures                                                                                                                       | `tests/fixtures/audio/*.wav` (generated, not committed)                                        | Synthesized by `npm run gen:audio` from `tests/helpers/signals.ts`.                                                                                          |
| QR codes                                                                                                                                  | `qr-codes/` (generated)                                                                        | `qrcode` npm package (MIT) via `npm run gen:qr`.                                                                                                             |
