# Decisions

Every judgment call made during the build, with the reason. When the spec was ambiguous the
safest kid-friendly option was chosen.

## Tooling

| Decision                                                                                    | Why                                                                                                                                                             |
| ------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| TypeScript **6.0.3**, not 7.x                                                               | typescript-eslint 8.72 supports TS `<6.1`; TS 7 (native) would break type-aware linting.                                                                        |
| Vite 8.3.5, Vitest 5.1, Playwright 1.64.1, ESLint 10, vite-plugin-pwa 2.0, Capacitor 8.6    | Current stable at build time; all pinned exactly in `package.json`, lockfile committed.                                                                         |
| `tsx` runs the scripts (`gen:audio`, `gen:levels`, `gen:qr`, `validate-levels`, Lighthouse) | Scripts reuse the real `src/` modules (signals, physics, generator) with no build step.                                                                         |
| Lighthouse 13 added as a dev dependency and `test:lighthouse` appended to `verify`          | Spec 15.4 lists Lighthouse as a gate. Lighthouse ≥ 12 has no PWA category, so "installable" is asserted in e2e with CDP `Page.getInstallabilityErrors` instead. |
| Vite `base: './'`                                                                           | One build works on any GitHub Pages repo path, a custom domain, and Capacitor.                                                                                  |

## Breath detection

| Decision                                                                                                                                                                 | Why                                                                                                                                                                                                                                                                                                                                                              |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Final thresholds (`src/config.ts`): `marginDb 6`, `flatnessMin 0.08`, `lowBandMin 0.40`, `tonalityMax 0.40`, `onsetMs 80`, `releaseMs 120`, attack 40 ms, release 150 ms | Measured on the synthetic fixtures at 44.1 k and 48 k: blow frames have flatness ≥ 0.17, low-band ratio ≥ 0.47 (10th pct), tonality ≤ 0.25; speech/singing/music have flatness ≈ 0–0.02 and tonality ≥ 0.46. The initial `lowBandMin 0.55` rejected ~30 % of blow frames, so it was lowered. Real-device tuning is tracked in QA_CHECKLIST.md.                   |
| Flatness is per frame, per bin (standard definition)                                                                                                                     | A single unaveraged periodogram of white noise has flatness ≈ 0.56, not 1 (exponential bin statistics). The unit test checks "≈ 1 for white noise" on a frame-averaged spectrum (> 0.9) and also that one raw frame is > 0.45, and "≈ 0 for a tone" (< 0.02). Grouping bins to push white noise to 1 would blur harmonic speech into noise and weaken rejection. |
| Tonality computed on a 2× decimated signal with prefix-sum energy normalization                                                                                          | Keeps autocorrelation over 80–400 Hz lags cheap enough for low-end phones (~190 k MACs/frame).                                                                                                                                                                                                                                                                   |
| Features use the AnalyserNode's dB spectrum in the browser and an identical Blackman-window FFT in tests                                                                 | Same math everywhere; all spectral features are scale-invariant so the AnalyserNode's dB offset does not matter.                                                                                                                                                                                                                                                 |
| Intensity holds its last mapped level across the release-hysteresis gap                                                                                                  | Prevents a visible dip during a 60 ms breath gap (the hysteresis test).                                                                                                                                                                                                                                                                                          |
| Sensitivity scales the mapped intensity only (not the candidate threshold)                                                                                               | As specified; it never makes talking lift the balloon.                                                                                                                                                                                                                                                                                                           |
| Calibration noise floor uses median + 2 × **robust** standard deviation (1.4826 × MAD)                                                                                   | One stray clap or bump during "Shhh…" would otherwise inflate the floor; median + 2σ is kept as specified, σ estimated robustly.                                                                                                                                                                                                                                 |
| Calibration also fails with "I didn't hear a blow" when < 6 candidate frames occur                                                                                       | A silent "blow" phase cannot produce a meaningful max.                                                                                                                                                                                                                                                                                                           |
| Calibration auto-continues 1.8 s after success (button also shown)                                                                                                       | Keeps the game breath-only after the first tap.                                                                                                                                                                                                                                                                                                                  |
| Calibration fallback after 3 failures enables tap **and** hum (behind the gate)                                                                                          | Covers kids who cannot blow or hum.                                                                                                                                                                                                                                                                                                                              |
| Calibration is stored per device (`shared`) and per profile (`byProfile`)                                                                                                | It runs before a profile exists on first run; per-profile values override when present.                                                                                                                                                                                                                                                                          |
| Party re-check rebases the stored calibration to the measured floor (never lowers it)                                                                                    | A noisier room raises the floor; the dynamic range is kept.                                                                                                                                                                                                                                                                                                      |

## Flow and UI

| Decision                                                                                                                                                             | Why                                                                                                                                         |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| The splash _is_ the pre-explanation: friendly balloon + mic note, one big "Tap to start!" that creates the AudioContext and asks for the mic                         | Spec wants one initial tap; a separate "explain" screen would need a second tap before any play.                                            |
| After a successful mic start, screens beyond the splash load as one lazy chunk                                                                                       | Keeps initial JS at 54 KB (19 KB gzip) so Lighthouse Performance is ≥ 90 on mobile emulation; the chunk is precached by the service worker. |
| Transitions are idempotent: 250 ms router lock, same-id screens are not pushed twice, buttons/tiles ignore repeat taps for 400–500 ms, rewards are keyed by a run id | Edge case 16 (double taps, double rewards).                                                                                                 |
| Browser back: a guard history entry is re-pushed on every `popstate` and mapped to in-app back                                                                       | Back never leaves mid-level; on gameplay it pauses first, a second back goes to the menu.                                                   |
| Pause "Blow to continue!" needs a fresh blow sustained 400 ms, starting ≥ 700 ms after the pause card appears                                                        | A child still blowing when the tab blurred must not instantly unpause.                                                                      |
| A level starts only on the first blow ("Blow to fly!")                                                                                                               | Gives kids time; also means talking/music never even starts a flight (tested).                                                              |
| Finishing a level always shows at least 1 star (thresholds 40/70/95 % map to 1/2/3, < 40 % still shows 1)                                                            | "No harsh failure"; spec says results show 1–3 stars.                                                                                       |
| Level end: the scroll brakes to a stop over the landing pad, so the balloon lands just by stopping blowing                                                           | Every level is finishable without precise timing; gentle landing (vy ≥ −170) earns a bonus.                                                 |
| Ground bounce happens even while invulnerable (no heart lost)                                                                                                        | Otherwise the balloon could sink through the ground.                                                                                        |
| Shield absorbs one hit and still gives the 1.5 s invulnerability                                                                                                     | Avoids an immediate second hit.                                                                                                             |
| Horizontal wind changes the scroll speed (the balloon's screen x stays fixed)                                                                                        | Spec fixes the balloon's x on screen.                                                                                                       |
| Night Sky darkness is purely visual (mask with light around the balloon and fireflies)                                                                               | Visibility must not change physics; the bot's solutions remain valid.                                                                       |
| Space low gravity = 0.45 ×                                                                                                                                           | "Tiny puffs go far": hover intensity drops from 0.45 to 0.20.                                                                               |
| Balloon visuals are drawn larger than the 42-unit collision circle                                                                                                   | Forgiving hits for small kids; basket bottom is aligned with the physics ground contact.                                                    |
| Look-ahead capped at 1400 units with a 150-unit fade; balloon screen x = min(30 % width, 420)                                                                        | Identical gameplay information on phones and ultrawide laptops (Daily/Party fairness).                                                      |
| Colours: button colours darkened to ≥ 4.5:1 with white text; colorblind palette is Okabe–Ito based, also darkened                                                    | Lighthouse accessibility 100 and kid readability.                                                                                           |
| `user-scalable=no` removed from the viewport meta                                                                                                                    | Accessibility (pinch-zoom); gameplay uses `touch-action: none` on the canvas instead.                                                       |
| Debug keyboard only exists with `?debug=1`                                                                                                                           | As specified; never in normal UI.                                                                                                           |
| Rest-break counter counts time spent _blowing_ during gameplay; the card resumes on OK or by blowing                                                                 | "3 minutes of continuous blowing play".                                                                                                     |
| Auto graphics quality: if the average fps during gameplay is < 40 over a 5 s window, quality drops to low (DPR 1, no parallax, no particles)                         | Edge case 13.                                                                                                                               |
| Settings lets a grown-up change a profile's buddy (avatar) by tapping it; skins are chosen in the Shop                                                               | Spec lists "avatar and balloon skin" under Profile & data.                                                                                  |
| Party: avatars are picked by tapping a slot to cycle; no names (optional per spec); each turn is capped at 75 s                                                      | No typing needed; a cap keeps the phone moving round the room.                                                                              |
| Party/Endless distance is in metres = world units / 10                                                                                                               | Friendly numbers.                                                                                                                           |
| Calm Breathing copy makes no medical or therapy claims (checked by an e2e test)                                                                                      | Spec 5.5.                                                                                                                                   |
| Candles count is random 3–8 per round                                                                                                                                | Spec "3–8 candles".                                                                                                                         |

## Courses and levels

| Decision                                                                                                                                                                                                                                                                                                                                | Why                                                                                                                                                                               |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| All courses are generated **trajectory first**: zones → a kid-like reference "breathing pilot" (exhale 1.6–3.4 s, inhale 0.5–1.1 s, intensity ≤ 0.8 in 0.1 steps at 10 Hz) flies the real `LevelSim` → stars on that path → hazards only where they keep ≥ 44–62 units of clearance from it                                             | Every course has a known fair, hit-free, all-stars solution by construction; the bot then verifies independently.                                                                 |
| The 30 Adventure levels are authored by `npm run gen:levels` and committed as JSON; a seed is kept only if the bot solves it                                                                                                                                                                                                            | "Levels are defined as JSON validated by schema.ts"; generated levels are still data.                                                                                             |
| Each world adds one mechanic; earlier mechanics can reappear lightly (e.g. trees from 1-3, wind in late world 4)                                                                                                                                                                                                                        | Spec table plus variety. Power-ups appear from World 2.                                                                                                                           |
| Level lengths 46–72 s; the schema rejects anything outside 45–90 s                                                                                                                                                                                                                                                                      | Spec 5.1.                                                                                                                                                                         |
| `validate-levels` runs before `vite build`                                                                                                                                                                                                                                                                                              | "An invalid level is a build failure."                                                                                                                                            |
| Bot: beam search (widths 60 → 150 → 320 on retry) over 11 intensity levels at 10 Hz, real Physics + Collision via `LevelSim`; any collision (even shield-absorbed) prunes a path; fairness rules are search constraints: > 0.85 for > 3 s is forbidden, and on/off segments must last ≥ 0.2 s (≤ 2.5 Hz toggling, under the 4 Hz limit) | Spec 15.3. A separate `fairness()` re-check runs on every solution.                                                                                                               |
| Endless: 14 s chunks chained deterministically (each starts where the previous reference path ended); first 320 units of a chunk are hazard-free; difficulty and speed ramp per chunk                                                                                                                                                   | Lets 200 chunks be bot-checked in isolation while runtime play is seamless. Old chunks are dropped (flat memory).                                                                 |
| Daily: mechanics = union of worlds 1..max(3, unlocked); course id includes that count                                                                                                                                                                                                                                                   | Spec: "worlds 1–3 only if fewer are unlocked". Everyone with ≤ 3 worlds gets the identical course; the bot checks 60 consecutive seeds for both the 3-world and 6-world variants. |
| Daily midnight rule: the day key is captured when the run starts                                                                                                                                                                                                                                                                        | "A run started on day N stays day N's run".                                                                                                                                       |
| Daily clock tampering: a date earlier than the last completion still plays and rewards once for that key, without touching the streak                                                                                                                                                                                                   | "Guard lightly, don't block play".                                                                                                                                                |

## Storage

| Decision                                                                                                                                    | Why                                                                                             |
| ------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| Schema v3 with migrations v1→v2 (calibration by device, pending unlocks) and v2→v3 (per-profile calibration, profile fields, daily)         | "A migration function per schema version, each unit-tested"; v1/v2 document the earlier shapes. |
| Daily state is stored per profile (`daily[profileId]`)                                                                                      | Streaks belong to a child, not the device.                                                      |
| On load every field is sanitized (clamped, defaulted); unknown/newer versions are treated as corrupt (backed up to `lbr.save.corrupt.<ts>`) | Never crash on bad data.                                                                        |
| Cross-tab: `storage` events reload the save when not mid-level; mid-level the reload is deferred to the next safe point                     | Edge case 18, last writer wins.                                                                 |
| Capacitor: Preferences plugin preloaded into a sync in-memory backend with write-through                                                    | Same synchronous `StorageBackend` API everywhere.                                               |

## Audio out

| Decision                                                                                                                | Why                                                        |
| ----------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------- |
| All SFX and music are synthesized with Web Audio (no files)                                                             | No licensing, tiny download, fully offline. See ASSETS.md. |
| Music is a tiny step sequencer (one loop per world + menu, calm, party); default volume 40 %, ducked 50 % while blowing | Spec 3.5 / 11.                                             |
| Calm music is off by default                                                                                            | Speaker feedback (spec 5.5).                               |

## QR unlocks

| Decision                                                                                     | Why                                                              |
| -------------------------------------------------------------------------------------------- | ---------------------------------------------------------------- |
| Codes are client-side in `unlocks.json` and therefore discoverable                           | Acceptable for cosmetic unlocks (spec 8.1).                      |
| A valid code becomes a pending unlock immediately and the `unlock` param is stripped at boot | Survives the first-run flow and reloads before a profile exists. |
| On Android, App Links are handled via Capacitor `appUrlOpen` / launch URL                    | Same code path as the web `?unlock=`.                            |
| The default `gen:qr` host is a placeholder; pass `--host` with the real URL                  | The real hosting URL is not known at build time.                 |

| e2e seeds calibration through `window.__lbrTestConfig` (honoured only in the `e2e` build mode)                                                                                                                                                             | The fake device id is not known in advance and calibration must be skipped for non-blow fixtures. | `window.__lbr` exposes read-only state plus a `control` object (scripted intensity, flush, suspend audio)                                                                                                                                                  | Spec asks for a test hook to drive level 1-1 by a scripted sequence; the hook is in a separate module imported only when `MODE === 'e2e'` and an e2e test asserts it is absent from the production build and bundle text.                                                                       |
| Perf test launches Chromium with GPU rasterization                                                                                                                                                                                                         | Default headless Chromium rasterizes canvas in software **on the main thread**; a 4× CPU throttle then throttles the rasterizer, measuring the rig (≈ 20–27 fps even with JS at < 8 % of frame time). | Perf durations: default 30 s fps window and heap at 15 s vs 60 s; `PERF_FULL=1` runs the spec's 2 min and minute 1 vs minute 10                                                                                                                            | Keeps `verify` practical; the full run is documented in the README.                                                                                                                                                                                                                             |
| Visual regression: Playwright screenshot baselines (`tests/e2e/__screenshots__`) are created on first run (`updateSnapshots: 'missing'`) and compared afterwards, plus geometric no-overlap/no-clipping/≥ 56 px assertions                                 | Screenshot assertions on the main screens at the four viewports.                                                                                                                                                                                                                                |
| WebKit project: Playwright's Windows WebKit build has **no Web Audio and no mediaDevices**; the test then verifies graceful degradation (boot, tap fallback, menus, gate). Where Web Audio exists it suspends the context and asserts a gesture resumes it | The resume path cannot run in that WebKit build; real Safari/iOS is covered by manual QA.                                                                                                                                                                                                       |
| Tests pause ~300–600 ms between rapid navigations                                                                                                                                                                                                          | The double-tap guards intentionally drop taps faster than a child can make them.                                                                                                                                                                                                                |

## Late changes from the verify loop

| Decision                                                                                                                                                | Why                                                                                                                       |
| ------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| Playwright uses one web server (`scripts/e2e-server.ts`) that builds the e2e and production bundles one after the other, then serves both (4173 / 4174) | Two Vite builds started in parallel by Playwright crashed on Windows (exit 0xC0000005).                                   |
| The perf test runs in its own Playwright project that depends on the others, so it runs alone                                                           | Sharing the CPU with other test browsers produced a 346 ms stall and 46.9 fps; alone: 59.4 fps, no long tasks.            |

## Final self-review (spec 15.6)

Every section of GAME_SPEC.md was checked against the code. Result of the last `npm run verify`:
typecheck ✓, lint 0 warnings ✓, 114 unit tests ✓ (99.7 % lines on the gated modules),
44 e2e tests ✓ (59.4 fps under 4× throttle, heap +0.04 MB), 36 level-bot checks ✓ (30 levels,
200 Endless chunks, 2 × 60 Daily seeds), build ✓ (30 levels validated), Lighthouse 98 / 100 / 100 ✓.
No `TODO`/`FIXME` in `src/`.

Deviations from the spec, with reasons:

1. **Manual device QA (15.5) not done**: needs physical devices; QA_CHECKLIST.md is ready and empty.
2. **Android APK not compiled here**: no Android SDK/Java on the build machine. The Capacitor project is generated and configured; `npm run android` builds it in Android Studio.
3. **WebKit AudioContext resume path** is not exercised in CI: Playwright's Windows WebKit has no Web Audio. The test asserts graceful fallback there and the resume path where Web Audio exists; real Safari is on the manual checklist.
4. **Perf test uses GPU rasterization**, and default `verify` durations are shortened (`PERF_FULL=1` for the spec's 2 min / minute 1 vs 10). See Testing above.
5. **Flatness ≈ 1 for white noise** is tested on a frame-averaged spectrum (per-frame periodograms give ≈ 0.56 by statistics).
6. **Installable** is checked with CDP instead of Lighthouse (Lighthouse 12+ removed the PWA category).
7. **Splash doubles as the mic pre-explanation** (one tap instead of two).
8. **Placeholders to replace before release**: Lucas & Friends character art, the `assetlinks.json` signing fingerprint, and the real hosting URL for `gen:qr` / the App Links intent filter.
9. **Not a git repository**: the spec asks to commit the lockfile; `package-lock.json` exists but nothing was committed because the folder has no repo.

## Changes requested after release testing

| Change                                                                                                                       | Notes                                                                                                                                                                                                                                                                                                                                |
| ---------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **All levels unlocked by default** (`settings.unlockAll`, default on; Settings › Accessibility & kids › "Unlock all levels") | Overrides spec 5.1's step-by-step unlocking by request. Progress, stars and coins are still recorded, so switching it off restores the 4-of-5 rule exactly. Older saves get the new default (on). The Daily course still follows _real_ progress (`unlockedWorldCount`), so Daily stays identical for everyone.                      |
| **Parental gate is math only** (no 3-second hold)                                                                            | Overrides spec 7 by request. A wrong answer, Back or Esc closes the gate, so a child guessing gets one try per opening (1 in 3).                                                                                                                                                                                                     |
| **"Try another way" shown by default** on the start screen, from the start of calibration, and on Mic Help                   | Overrides spec 3.4/9 (fallback after 3 failures, behind the gate) by request. It switches to tap & hold play without asking for the mic; the in-game prompt becomes "Tap and hold to fly!". Settings is still gated, and the tap/hum toggles inside it no longer ask a second time. Turning tap mode off in Settings starts the mic. |
| Local Playwright runs use 2 workers (3 on CI)                                                                                | Fake-mic tests start one browser each; on an 8 GB machine with other apps open, 3 workers ran out of memory and crashed test tabs.                                                                                                                                                                                                   |
